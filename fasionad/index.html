01 · The Critical Dilemma

왜 기존 자율주행은 비 오는 날 골목길에서 멈칫할까?

현재 모빌리티 업계는 두 가지 극단적인 방식 사이에서 깊은 딜레마에 빠져 있습니다. 하나는 너무 급하고, 다른 하나는 너무 느립니다.

순수 E2E 신경망 (기존 방식) 초고속 30ms

빠르지만, 돌발 상황에서 멍청해진다

센서 영상을 입력받아 곧바로 핸들/페달 명령을 출력하는 방식. 일상 주행에서는 사람처럼 매끄럽지만, 데이터셋에 없던 공사 현장이나 경찰관 수신호 같은 '롱테일(Long-tail) 엣지 케이스'를 만나면 완전히 길을 잃습니다.

장점: 30ms 이내 실시간 조향 반응 (실시간성 충족)
치명적 한계: 블랙박스 구조로 인과관계 추론 불가능
위험: 낯선 도로 환경에서 에러 누적으로 인한 급정거/사고
대표 사례: VAD, GenAD 기본형 충돌률 0.53% 수준

02 · The Solution Architecture

FASIONAD : 두 개의 경로와 지능형 스위칭

교수님 5분 질의응답 완벽 대비 가이드

FASIONAD 내용 이해도 검증 핵심 포인트
Q1. Fast(30ms)와 Slow(1초 이상)의 극심한 시간차를 어떻게 충돌 없이 비동기 융합했습니까?

답변 포인트: Slow Pathway의 VLM은 직접 차량의 액추에이터(조향각/스로틀)를 실시간 조작하지 않습니다. 대신 고수준의 'Planning State Vector (Pt)'와 'Meta-Action (At)'만을 비동기 생성하여 Fast Pathway의 Ego Token과 Cross-Attention으로 부드럽게 결합합니다. Fast Pathway는 평상시 지연 없이 6.9+ FPS로 달리다가, Slow의 피드백이 도착했을 때만 잠재 공간(Latent Space)에서 궤적을 미세 재보정하므로 차량이 멈추거나 덜컹거리지 않습니다.

Q2. 거대 VLM이 엉뚱한 판단을 내리는 환각(Hallucination) 위험은 어떻게 막았나요?

답변 포인트: 본 연구에서는 정보 병목 이론(Information Bottleneck, IB)을 도입했습니다. 주행에 불필요한 시각적/언어적 노이즈를 3계층 MLP를 통해 걸러내고, PPO(Proximal Policy Optimization) 기반의 보상 유도 손실함수(L_rvlm)로 VLM을 미세조정했습니다. 또한 VLM의 피드백 보상 점수가 지나치게 신뢰도가 낮으면 이를 즉시 폐기하고 기존 안전 궤적을 유지하는 방어 로직이 적용되어 있습니다.

Q3. 일반적인 가우시안 대신 왜 라플라스 분포(Laplace Distribution)를 썼습니까?

답변 포인트: 가우시안 분포는 평균 근처 데이터에 최적화되어 있으나 제곱 오차(L2)를 사용하여 이상치에 민감합니다. 반면 라플라스 분포는 두터운 꼬리(Heavy-tailed) 특성과 L1-절대오차 기반으로 설계되어, 도로 위에서 드물게 발생하는 극단적 노이즈나 돌발 이상치(Outlier)를 지나치게 증폭시키지 않고도 안정적으로 불확실성을 모델링할 수 있기 때문입니다.
